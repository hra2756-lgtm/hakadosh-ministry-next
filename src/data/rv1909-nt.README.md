# Reina-Valera 1909 New Testament

`rv1909-nt.json` contains the complete Spanish New Testament in Reina-Valera
1909 (RV1909), a public-domain translation. The historical spelling and accents
are preserved; this is not RVA-2015 or NVI.

- Source: https://ebible.org/find/details.php?id=spaRV1909
- Public-domain statement: https://ebible.org/spaRV1909/copyright.htm
- Source archive: https://ebible.org/Scriptures/spaRV1909_usfx.zip
- Retrieved: 2026-11-11
- Archive SHA-256: `6fd2db9b7b865f8f0c7eeb9ca859a52e36d532ca8d5a35fbf746310436197b48`

To regenerate, download and extract the archive, then run with Python 3:

```sh
python scripts/build-rv1909-nt.py /path/to/spaRV1909_usfx.xml
```

The importer removes XML formatting, Strong's annotations, and non-scriptural
notes/headings, normalizes whitespace, and preserves verse text. English book
identifiers match `kjv-nt.json`; displayed references use Spanish book names.
The import fails if references are duplicated, empty, or differ from the English
New Testament. Runtime selection uses the existing English daily verse and
looks up its Spanish counterpart by book, chapter, and verse.

## Verse numbering

The source has two empty verse markers because RV1909 numbers these passages
differently. The importer explicitly aligns the existing Spanish sentences with
KJV while retaining the original Spanish reference for display:

- KJV Acts 19:40-41 splits the text of RV1909 Hechos 19:40.
- KJV 2 Corinthians 13:12-13 splits RV1909 2 Corintios 13:12.
- KJV 2 Corinthians 13:14 corresponds to RV1909 2 Corintios 13:13.

For the three references with different displayed numbers, `kjvReference`
provides the equivalent passage and the Spanish panel explains the difference.
The importer checks the exact boundaries and fails if the upstream source
changes. No verses are translated or invented, and the English selection pool
and daily algorithm are unchanged.

Run `node --test scripts/verify-bilingual-verses.mjs` to check complete coverage,
Spanish text, passage alignment, and paired selection at Eastern-time day and
daylight-saving boundaries.
